# Portfolio — Wasiq

Next.js 15 · TypeScript · Tailwind CSS · Framer Motion

## Run

```bash
npm run dev
```

## Features

- Light/dark theme (light default, localStorage, no FOUC)
- Sections: Hero, Work, Services, Stack, About, Contact
- Case studies at `/projects/[slug]`
- Contact API at `/api/contact`
- Interactive: mascot, custom cursor (desktop), terminal (`), Konami, coffee + mood widgets
- Easter eggs: `cheatcode`, three hover jokes, mascot quips

## Notes

- Project videos are large (35–100MB). Compress to WebM/MP4 under 2MB before wiring hover previews.
- Sounds are stubbed and off by default — drop files in `/public/sounds` when ready.
- Update links in `src/data/profile.ts` with real GitHub / LinkedIn / Upwork / email.
